# Shape briefs (historical UI)

These files are **Impeccable shape / design briefs** from mid-September 2026. They informed early screen layouts. Domain nouns in them often predate [CONTEXT.md](../CONTEXT.md) and ADR-0002 (they still say **KpiCycle**, **KpiSet**, HR opens the cycle, manager-only agree).

**Do not treat them as product truth.** For vocabulary and KPI rules use CONTEXT + `docs/adr/`. For scope use [PRODUCT.md](../PRODUCT.md). For tokens use [DESIGN.md](../DESIGN.md).

Keep the briefs when checking “what UI direction was confirmed,” then translate nouns to the glossary before coding.

# Indonesia PublicHolidays via Titimangsa, with sticky Admin remove

**PublicHoliday** stays one named date for the Tenant. Indonesia **Libur Nasional** and official **Cuti Bersama** are filled from the live Titimangsa API when Admin opens Project Admin configure or clicks Refresh, for the current and next Asia/Jakarta years. Any Admin-added date is labeled **Cuti Bersama (Internal)**, even when its name is not cuti bersama. Admin may still add, rename, or remove. Remove of an Indonesia date is a soft suppress keyed by date so a later refresh does not restore it; Admin may re-add that date by hand as Internal. Refresh only adds missing dates and does not overwrite a local name. If the API fails, the current list stays and the product shows an error.

We rejected an embedded-only calendar (stale without a ship) and rejected scheduled background sync (no worker in this slice). We rejected restoring removed Indonesia dates on refresh, because that would make Admin remove fake. We rejected separate domain types per origin; the three labels are marks on one PublicHoliday.

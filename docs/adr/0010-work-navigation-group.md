# Work delivery has its own navigation group

The sidebar has three groups: People (Home, People, Organization), Performance (My KPI, Team KPIs, KPI Admin, KPI Tree), and Work (Projects, Timesheet, Leave, plus Leave requests and Project Admin for Users with the Admin grant). CV review stays a People subpage. Payslips stay out.

We rejected keeping Phase 1 navigation as People / Org / CV / KPI only. Projects, Timesheet, and Leave were already built and in use, and hiding Timesheet and Leave behind a link on one's own profile left daily work unreachable. We rejected one "Leave" page that both files and decides: filing is for everyone, deciding is the Admin grant, and the two screens answer different questions.

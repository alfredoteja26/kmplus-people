# Admin is a User grant, not an exclusive login hat

**Admin** is a grant on chosen Users. It covers KPI governance, and it covers opening a **Project** and maintaining that Project’s **ProjectCode**, name, client name, and dates. Any Admin may change those fields on any Project. It also covers **Staffing**: any Admin may add a Person, end that row, or delete a row that was a mistake. It may stack with Employee or Manager so that Person can still hold a **KpiPortfolio**. HR and Tenant admin do not imply Admin. HR or an existing Admin grants or revokes it; several Users may hold it.

We rejected a fourth exclusive login hat (that would stop the Admin from being a pekerja) and rejected treating today’s Tenant admin as KPI Admin by default. We rejected a separate grant only for opening a Project, because the same people already hold Admin. Project reports, time-block types, and the all-staff absence view are not part of this grant yet.

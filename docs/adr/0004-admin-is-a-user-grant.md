# Admin is a User grant, not an exclusive login hat

**Admin** is KPI governance assigned to chosen Users. It may stack with Employee or Manager so that Person can still hold a **KpiPortfolio**. HR and Tenant admin do not imply Admin. HR or an existing Admin grants or revokes it; several Users may hold it.

We rejected a fourth exclusive login hat (that would stop the Admin from being a pekerja) and rejected treating today’s Tenant admin as KPI Admin by default.
